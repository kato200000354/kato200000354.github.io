# kato200000354.github.io

つくったゲームとアプリの作品集サイト。 https://kato200000354.github.io/

- `/index.html` … トップ（作品一覧）
- `/works.json` … 作品リスト。作業フォルダの `_site-tools/publish.mjs` が新作を自動で追記する（説明文などは手で直してよい）
- `/apps/<名前>/` … このリポジトリで公開している作品
- `/thumbs/` … 一覧用サムネイル（420×560）
- `/imakoto/`・`/ekakiuta/`・`/shake-fever/` … それぞれ別リポジトリで公開
- `/.well-known/assetlinks.json` … Android アプリ「いまコト」とこのサイトを結びつける証明ファイル（消さないこと）
