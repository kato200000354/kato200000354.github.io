ふっとびFIGHTERS
ストック 3

下のカードをタップして選ぶ人を切り替え、上のファイターをタップ。ボタンで「プレイヤー / CPU / なし」を変更できます。

操作説明

プレイヤー1プレイヤー2ゲームパッド
移動AD←→スティック / 十字
ジャンプW か Space↑X / Y（スティック上でも）
しゃがむS↓スティック下
攻撃J, か テンキー1A
必殺ワザK. か テンキー2B
シールドL/ か テンキー3L / R / ZL / ZR
ポーズEsc か PSTART

人間がひとりだけのときは、両方のキー配置どちらでも操作できます。スマホでは画面のスティックとボタンで遊べます（横持ちがおすすめ）。

テクニック

スマッシュ攻撃方向キーと攻撃を同時に押す。攻撃を押しっぱなしでため。ダメージが溜まった相手をふっとばそう
強攻撃方向キーを押しながら攻撃（上・下・横）
ダッシュ攻撃走りながら攻撃
空中攻撃空中で 攻撃 / 前・後ろ・上・下＋攻撃（下は相手をたたき落とす）
必殺ワザ必殺ボタン / 横・上・下＋必殺。上必殺は復帰ワザ（使ったあとは着地するまで無防備）
回避シールド中に左右 = 転がり、下 = その場回避、空中でシールド = 空中回避
崖つかまりステージの端に近づくと自動でつかまる。上 = ジャンプ、ステージ側 = 登る、外側 = はなす
すり抜け / 急降下浮いた足場で下 = すり抜け、空中で落ちながら下 = 急降下
