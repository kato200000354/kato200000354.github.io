遊び方
  • 手札を先に全部出しきった人が勝ち。あなたとCPU3人の4人対戦です。
  • 強さは 3 < 4 < … < K < A < 2 < ジョーカー。場と同じ枚数・同じ形で、より強いカードを出します。
  • カードをタップして選び「出す」。出せない・出したくないときは「パス」。全員がパスすると場が流れ、最後に出した人から再開します。
  • ジョーカーは好きなカードの代わりになります（ペアや階段の穴埋めにも使えます）。
  • 2ラウンド目からはカード交換があります。大貧民は一番強い2枚を大富豪へ、貧民は1枚を富豪へ。大富豪・富豪はいらないカードを選んで返します。
  • 得点は 大富豪3・富豪2・貧民1・大貧民0。全ラウンドの合計で順位が決まります。
  • 「ヒント」を押すと、おすすめの出し方を選んでくれます。
