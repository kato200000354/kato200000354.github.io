いつもの商品が値下がりしたら LINE でお知らせ

はじめの設定（1回だけ・3ステップ）

商品リストを保存する場所（GitHub）に入るための「鍵」を作ります。PCでやるのがおすすめです（あとでQRコードでスマホに移せます）。

1
下のボタンで GitHub を開く
名前・期限・権限はもう入力済みになっています。ログイン画面が出たらログインしてください。
GitHub で鍵を作る画面を開く ↗
2
1か所だけ選んで「Generate token」
開いた画面を少し下へ。
「Repository access」の Only select repositories を押す → 出てきた「Select repositories」で nesage-watch を選ぶ。
いちばん下の緑の Generate token → 確認画面でもう一度 Generate token。
日本語に翻訳して見ているとき：「リポジトリへのアクセス」→「選択したリポジトリのみ」→「リポジトリを選択」で nesage-watch →「トークンを生成」。
3
出てきた鍵をコピーして、ここに貼る
github_pat_ で始まる長い文字です（横のコピーボタンでコピーできます）。この画面を閉じると二度と表示されないので注意。

鍵はこの端末の中だけに保存され、GitHub 以外には送りません。

しくみ・設定

家のPCが起動しているあいだ、3時間おきに Amazon の価格を調べます（PCを起動したときにも1回）。前回より安くなっていたら（目標価格を決めた商品はそれ以下になったら）LINE に通知します。登録した商品は次のチェックで価格がわかります。

スマホのカメラでこのQRを読むと、鍵の設定が済んだ状態で開きます。
