📉 ねさげ見張り番

いつもの商品が値下がりしたら LINE でお知らせ

はじめの設定（1回だけ）

登録した商品は GitHub の非公開リポジトリ nesage-watch に保存します。読み書きするための「鍵（トークン）」を作って貼り付けてください。

  1. GitHub のトークン作成ページを開く
  2. 名前は「ねさげ見張り番」、期限は好きな長さ
  3. Repository access →「Only select repositories」→ nesage-watch
  4. Permissions →「Contents」を Read and write
  5. 「Generate token」を押して、出てきた github_pat_… をコピー

トークンはこの端末の中だけに保存され、GitHub 以外には送りません。

しくみ・設定

家のPCが起動しているあいだ、3時間おきに Amazon の価格を調べます（PCを起動したときにも1回）。前回より安くなっていたら（目標価格を決めた商品はそれ以下になったら）LINE に通知します。登録した商品は次のチェックで価格がわかります。
