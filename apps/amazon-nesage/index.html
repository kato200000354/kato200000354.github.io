📉 ねさげ見張り番

いつもの商品の値下がり・在庫切れをスマホに通知

🔒 招待された家族・友人だけが使えるアプリです。
使いたい方は、招待してくれた人から「招待リンク」か「QRコード」をもらってください。

招待リンクで始める

招待リンクを開くと自動で始まります。ホーム画面に追加したアプリで開いている場合などは、招待リンクをここに貼り付けてください。

作った人（管理者）向け：鍵を作る

商品リストを保存する場所（GitHub）に入るための「鍵」を作ります。PCでやるのがおすすめです。

1
下のボタンで GitHub を開く
名前・期限・権限が入力済みの画面が開きます。
途中でログインやパスワード確認の画面が出ると空欄になることがあります。そのときはこのボタンをもう一度押してください。
GitHub で鍵を作る画面を開く ↗
2
1か所だけ選んで「Generate token」
開いた画面を少し下へ。
「Repository access」の Only select repositories を押す → 出てきた「Select repositories」で nesage-watch を選ぶ。
いちばん下の緑の Generate token → 確認画面でもう一度 Generate token。
日本語に翻訳して見ているとき：「リポジトリへのアクセス」→「選択したリポジトリのみ」→「リポジトリを選択」で nesage-watch →「トークンを生成」。
もう一度押しても空欄のときは（手で入力）
  1. Token name（トークン名）… ねさげ見張り番（なんでもOK）
  2. Expiration（有効期限）… No expiration（有効期限なし）
  3. Repository access … 上の説明どおり nesage-watch を選ぶ
  4. Permissions（権限）の Add permissions（権限を追加）→ Contents（コンテンツ）を選ぶ → 横の Access を Read and write（読み取りと書き込み）にする
  5. Generate token（トークンを生成）

Contents は nesage-watch を選んだあとでないと出てきません。

3
出てきた鍵をコピーして、ここに貼る
github_pat_ で始まる長い文字です（横のコピーボタンでコピーできます）。この画面を閉じると二度と表示されないので注意。

鍵はこの端末の中だけに保存され、GitHub 以外には送りません。

あなたはどなたですか？

登録した商品と通知は、人ごとに分かれます。すでに別の端末で使っている人は、自分の名前を選んでください。

パスワードは、ほかの人があなたの名前を選んで使わないようにするためのものです。別の端末で自分の名前を選ぶときに使います。

📱 スマホのカメラでこのQRコードを読み取ってください

読み取ったスマホでは、名前選びやパスワードなしで さんとして使えます。
・1回だけ使えます。人には見せないでください。

Android でカメラ（Googleレンズ）から開いたときは、ページに出る「Chrome で開く」を押してください。
iPhone で通知も受け取るときは、開いたページの案内に沿って「ホーム画面に追加」してください。

⚠ パスワードがまだありません。このままだと、招待された人があなたの名前を選んで、あなたの商品を見たり変えたりできます。

商品を登録

しくみ・設定

作った人の家のPCが起動しているあいだ、3時間おきに Amazon の価格を調べます（PCを起動したときにも1回）。登録した商品は次のチェックで価格がわかります。商品を登録した人の端末に通知するのは次のときです。

  • 前回より安くなった（目標価格を決めた商品はそれ以下になった）
  • 同じ商品を、ほかの出品者が送料込みでいまより安く出している
  • 在庫切れ・取り扱い終了になった／また買えるようになった

家族・友人を招待する

スマホのカメラでこのQRを読むと、すぐに使い始められます。

⚠ 招待リンクを持っている人は、このアプリのみんなの商品リストを見たり変えたりできます。家族や信頼できる友人にだけ送ってください。
